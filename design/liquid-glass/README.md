## 做法

### 1. 四层灰阶

| 层级 | 颜色 | 用在哪 |
| --- | --- | --- |
| 页面底 | `#EEF1F4` | 应用背景 |
| 卡片 | `#FFFFFF` | 侧栏、顶栏、表格、表单、登录卡 |
| 控件 | `#F4F6F9` | 输入框、搜索、分段控件、代码底 |
| 选中 | `#EDF2FC` | 选中行、当前返回体、草稿卡 |

没有阴影，没有模糊，没有半透明白。分区只靠色阶差和 14px 间距。

### 2. 无描边

没有 `border`，也没有 1px 白线。表格行靠 46px 行高和白/浅蓝底色区分：

- hover：`#F6F8FB`
- 选中：`#EDF2FC`
- 待确认：`#F2F6FD`

### 3. 一个信号蓝

`#3568D4` 只出现在：

- 选中行 / 当前返回体
- 开关、checkbox
- 未保存圆点、待确认草稿
- 登录按钮以外的少量强调

主按钮和激活导航用石墨黑 `#17191D`，其余全部是灰阶和语义色（成功绿、警告琥珀、错误红）。

### 4. 一套图标

导航图标统一为 24 网格的实心图标、18px 显示：接口是插头（端口），文件是文件夹，变量是标签，统计是柱状，团队是双人，日志是列表，设置是滑杆。

### 5. 圆角

- 面板 / 卡片：16px（侧栏 20，顶栏 14）
- 按钮 / 输入框：10px
- 标签 / 键盘键：8px
- 开关 / 头像：999px

## 落到代码时

1. 先在 `variables.scss` 里把阴影全部置空，页面底色改成 `#EEF1F4`。
2. `AppLayout.vue` 的侧栏和顶栏改成纯白块，去掉 `box-shadow` 与半透明背景。
3. `ApiList.vue`：去掉表格边框和行分割线，行高 46，选中行用 `#EDF2FC`。
4. `ApiEdit.vue`：输入框改成 `#F4F6F9` 实色底，代码区用 `#F7F8FA`。
5. 助手面板去掉浮层阴影，草稿卡用浅蓝底 + 小标签区分。

## 注意

- 这是静态视觉稿，没有接真实接口，数据为演示数据。
- 扁平化后，层级全靠灰阶和字重；如果以后要加深色模式，需要重新定义 4 层灰阶。
- 当前按 1440 × 900 桌面端排版；1280 宽需要隐藏“负责人”或“最近调用”一列。
