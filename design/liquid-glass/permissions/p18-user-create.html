两层角色

全局
USER / SUPER_ADMIN决定能否进入系统管理：账号、团队、全局设置、MCP 策略。
团队
可编辑 / 只读 / 团队管理员只决定在某个团队内能做什么，换团队就换角色。

权限边界

  • 超级管理员不自动获得团队内的编辑权，进入团队仍需以该团队身份操作。
  • 团队管理员只能管理本团队，无法创建账号或新建团队。
  • 移出团队不影响账号本身，接口资源留在团队。
