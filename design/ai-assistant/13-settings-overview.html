设置分类 + AI 供应商

把原来一页到底的全局设置拆成「AI 能力 / 系统」两组，仍然只占侧边栏一个「全局设置」入口。AI 供应商从助手配置里独立出来，先支持 API Key 接入，并为 DeepSeek、Kimi、MiniMax、智谱 GLM 等预填默认地址与模型。

设计原则
分类是为了减少单页长度，不是增加导航层级。
01
一个入口，组内分类
侧边栏仍然只有「全局设置」；进入后用左侧子导航切换 AI 能力、系统、日志与文件存储。
02
供应商与能力分离
供应商负责地址、模型与 Key；助手页只负责启用、能力开关与使用范围。换模型不用再翻一整页。
03
预设但可改
选中供应商自动填默认 Base URL 与模型，字段仍可编辑；自定义入口承接任意 OpenAI 兼容服务。
分类结构
每个分类只承载一类设置；保存按钮留在当前分类底部。

交互说明
以下行为需要在实现时一起落地。
切换供应商
点击卡片后自动填入 Base URL 与默认模型，并清空已测试状态；如果当前已填自定义值，弹二次确认再覆盖。
Key 与测试
Key 只写不回显；未保存的新 Key 不能测试，保存后测试按钮才可用；测试结果带耗时与时间。
未配置降级
供应商未填 Key 时，助手页顶部显示「未配置」，编辑器 AI 按钮隐藏；对话入口仍在，但打开后给出配置引导。
