MCP Server

把 MockHub 的检索、统计与生成能力开放给 Claude、Cursor、Codex 等外部 AI 工具。

启用 MCP Server
外部客户端通过 Bearer Token 调用，权限与 Token 所属用户一致
已启用
服务地址
https://mockhub.example.com/mcpSSE
本地部署时使用 http://<host>:8080/mcp；连接示例见文档。

可用工具

工具内部复用现有业务服务，不会绕过权限与团队隔离。

mockhub.search_apis 按关键字搜索接口 读
mockhub.get_api_detail 读取接口与返回体配置 读
mockhub.get_api_stats 查询调用次数、最近调用与僵尸 Mock 读
mockhub.create_api_draft 根据描述生成接口草稿 写
mockhub.apply_api_draft 应用草稿（默认需 Web 确认） 写
mockhub.generate_response_body 生成 JSON / XML 响应体 写
mockhub.generate_conditions 把自然语言转成条件规则 写
mockhub.explain_match_result 解释一次请求的命中链路 读

写操作策略

外部 AI 工具默认只能创建草稿，最终写入必须由用户在 MockHub 页面确认。

草稿 + Web 确认（推荐）
返回确认链接，用户在 MockHub 完成最终确认
允许直接写入
风险较高，仅建议在隔离环境开启
